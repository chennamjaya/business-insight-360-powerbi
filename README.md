# Business Insight 360 — Power BI Dashboard

## Project Overview

Business Insight 360 is an interactive Business Intelligence dashboard built using Microsoft Power BI. It brings together business performance across Finance, Sales, Marketing, Supply Chain, and Executive reporting.

## Dashboard Preview

![Home Dashboard](Screenshots/Home Page.png)

## Dashboard Modules

- **Finance:** Revenue, gross margin, net profit, and financial performance.
- **Sales:** Customer and product performance, sales and profitability.
- **Marketing:** Market, segment, and product performance analysis.
- **Supply Chain:** Forecast accuracy, net error and absolute error.
- **Executive:** Consolidated KPIs and business performance insights.

## Tools and Skills

- Microsoft Power BI
- DAX
- Power Query
- Data Modelling
- Interactive Visualisations
- Field Parameters
- Bookmarks and Navigation
- KPI and Dashboard Design
